# Web Programming

Repository lưu trữ quá trình học tập và thực hành **Lập trình Web**.

## 📚 Nội dung

- **HTML**: Cấu trúc và nội dung trang Web
- **CSS**: Giao diện, bố cục, Flexbox, Grid, Responsive
- **JavaScript**: Logic, DOM, Event, Local Storage, Fetch API
- **Exercises**: Bài tập thực hành
- **Projects**: Các project Web

## 🛠️ Công nghệ

HTML5 · CSS3 · JavaScript · Git · GitHub

## 🎯 Mục tiêu

Nắm vững kiến thức Web cơ bản, thực hành qua bài tập và xây dựng các project thực tế.
